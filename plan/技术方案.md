### 1.2 架构决策

| 决策 | 选择 | 理由 |
|------|------|------|
| 前后端分离 | React + FastAPI | 前端独立开发部署，后端专注 API |
| 通信协议 | HTTP/REST + JSON | 简单成熟，调试方便 |
| 反向代理 | Nginx | 成熟稳定，可做静态文件服务和负载均衡 |
| 容器化 | Docker Compose | 单机部署足够，无需 Kubernetes 过度设计 |
| 语音识别 | Web Speech API | 浏览器原生，零延迟、免费、无服务器负担 |
| 文字转语音 | edge-tts | 开源免费，质量可接受，支持异步调用 |

#### 3.2.3 API 封装

```typescript
// api/request.ts
import axios from 'axios';

const api = axios.create({
  baseURL: '/api',
  timeout: 30000,
});

// 请求拦截器：自动附加 JWT Token
api.interceptors.request.use((config) => {
  const token = localStorage.getItem('token');
  if (token) {
    config.headers.Authorization = `Bearer ${token}`;
  }
  return config;
});

// 响应拦截器：统一错误处理
api.interceptors.response.use(
  (response) => response,
  async (error) => {
    if (error.response?.status === 401) {
      // Token 过期，尝试刷新或跳转登录
      await refreshOrLogout();
    }
    return Promise.reject(error);
  }
);

export default api;
```

#### 3.3.3 AI 对话服务设计

```python
# app/services/ai_service.py
class AIService:
    """AI 对话服务，封装与 LLM API 的交互"""
    
    def __init__(self, provider: str = "qwen"):
        # 从环境变量读取配置
        self.api_key = os.getenv("LLM_API_KEY")
        self.base_url = os.getenv("LLM_BASE_URL")
        self.model = os.getenv("LLM_MODEL", "qwen-plus")  # 默认用性价比最高的
        self.provider = provider
    
    async def chat(
        self,
        messages: list[dict],  # [{"role": "user", "content": "..."}]
        conversation_id: str,
    ) -> AsyncGenerator[str, None]:
        """流式生成回复，支持 SSE 推送给前端"""
        async with httpx.AsyncClient() as client:
            async with client.stream("POST", f"{self.base_url}/chat/completions",
                                     json={
                                         "model": self.model,
                                         "messages": messages,
                                         "stream": True,
                                         "temperature": 1.0,  # 更自然
                                     },
                                     headers={"Authorization": f"Bearer {self.api_key}"}) as resp:
                async for line in resp.aiter_lines():
                    if line.startswith("data: "):
                        chunk = line[6:]  # 去掉 SSE 前缀
                        yield chunk
```

**低成本策略**：
- 使用 Qwen-Turbo 作为默认模型（当前约 ¥0.5/百万 token）
- System prompt 中设置简洁指令，避免不必要的冗长回复
- 对话历史只保留最近 N 轮，控制 token 用量

    """使用 edge-tts 进行文字转语音"""
    
    async def generate(self, text: str, voice: str = "en-US-GuyNeural") -> Path:
        """
        生成语音文件
        
        Returns:
            音频文件的磁盘路径
        """
        output_dir = Path("/app/uploads/audio")
        output_dir.mkdir(parents=True, exist_ok=True)
        
        filename = f"{uuid4().hex}.mp3"
        output_path = output_dir / filename

        cmd = ["edge-tts", "--voice", voice, "--text", text, "--write-media", str(output_path)]
        await asyncio.create_subprocess_exec(*cmd)
        
        return output_path

### 3.4 安全设计

#### 3.4.1 认证机制

```
┌─────────────────────────────────────────────────────────┐
│                  JWT Token 流程                          │
│                                                         │
│  1. 用户登录 ──► POST /api/auth/login                   │
│  2. 后端验证 ──► 签发 access_token (7天) + refresh_token │
│  3. 前端存储 ──► localStorage.setItem('token', ...)     │
│  4. 后续请求 ──► Header: Authorization: Bearer <token>  │
│  5. 后端中间件──► JWTMiddleware.verify(token)           │
│  6. Token 过期 ──► 401 ──► 前端尝试 refresh              │
│  7. Refresh 失败 ──► 强制重新登录                       │
└─────────────────────────────────────────────────────────┘
```

**Token 配置**：
```python
# app/core/security.py
from datetime import timedelta
from jose import jwt, JWTError

SECRET_KEY = os.getenv("JWT_SECRET_KEY")  # 必须修改！
ALGORITHM = "HS256"
ACCESS_TOKEN_EXPIRE_DAYS = 7

```

#### 3.4.2 安全措施清单

| 威胁 | 防护手段 |
|------|----------|
| XSS | React 自动转义 HTML；CSP 头 |
| CSRF | SameSite Cookie + JWT 非 Cookie 存储 |
| SQL Injection | SQLAlchemy ORM + 参数化查询 |
| Brute Force | 登录失败次数限制 (limiter) |
| API Key 泄露 | 环境变量注入，不写代码中 |
| 敏感数据暴露 | API 响应去敏，不返回密码/hash |
| 大文件上传 | 限制上传文件大小 ≤ 10MB |

## 四、关键技术难点与解决方案

### 4.1 AI 对话流式响应

**问题**：AI 生成回复需要时间，用户不希望长时间等待首字。

**解决方案**：
1. 后端使用 FastAPI 的 `StreamingResponse` 实现 SSE（Server-Sent Events）
2. 前端接收到第一个字符后立即展示，后续文字逐个追加
3. 如果生成超时（> 10 秒），返回部分结果并标记"未完成"

### 4.2 多用户并发下的 SQLite

**问题**：SQLite 在高并发写入时会有锁竞争。

**解决方案**：
- Phase 1 用户量小时，WAL (Write-Ahead Logging) 模式足够
- 使用 `check_same_thread=False` 配合会话池
- 如果后期出现性能瓶颈，升级到 PostgreSQL

### 4.3 音频文件存储管理

**问题**：每次对话都产生音频文件，长期积累可能占满磁盘。

**解决方案**：
- 限制单个音频文件 ≤ 10MB（录制时长约 2 分钟）
- 超过 30 天的音频自动清理（定时任务）
- 50GB 硬盘预估：每天 100 个活跃用户 × 平均 10 条对话 × 每条 2MB ≈ 2GB/月

### 4.4 Web Speech API 兼容性

**问题**：Web Speech API 主要支持 Chrome，Safari/Firefox 可能不支持。

**解决方案**：
```typescript
// 降级策略
if ('webkitSpeechRecognition' in window || 'SpeechRecognition' in window) {
  // 使用浏览器原生 STT
  useNativeSTT();
} else {
  // 降级到键盘输入模式
  showTextInputFallback();
}
```
