# 数据库设计

## 一、选型决策

### 1.1 SQLite

**选择理由：**
- 嵌入式数据库，无需独立进程或网络访问
- 单文件存储，备份迁移方便（直接复制文件）
- 单机读写性能良好，适合本项目并发规模（少量用户）
- 零配置，开箱即用，开发环境和生产环境一致
- 支持 WAL (Write-Ahead Logging) 模式，提升并发读写性能

### 3.3 技术选型

| 项目 | 方案 | 备注 |
|------|------|------|
| 数据库引擎 | SQLite (WAL 模式) | 高并发读性能提升 |
| ORM | SQLAlchemy 2.0 | 异步支持，SQLAlchemy 2.0+ |
| Migrations | Alembic 1.13+ | SQLAlchemy 官方迁移工具 |
