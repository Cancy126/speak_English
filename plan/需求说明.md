# 口语练习网站 - 功能需求说明书

---

## 一、项目概述

### 1.1 项目背景
本项目是一个基于 AI 技术的英语口语练习 Web 应用，旨在通过 AI 对话 + 发音评测技术帮助用户高效提升英语口语能力。在确保高质量用户体验的前提下，通过开源方案实现低成本运行。

### 1.2 项目目标
- **核心目标**：提供一个高效、低成本的英语口语练习平台
- **体验目标**：提供接近真人交流的真实对话体验
- **体验目标**：降低英语学习门槛，让所有人都能便捷地进行口语练习
